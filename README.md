# Candy Crush – Match-3 Puzzle Game

## Project Overview

Candy Crush is a browser-based match-3 puzzle game developed using HTML, CSS, and JavaScript. The project demonstrates the implementation of interactive game mechanics, dynamic user interface updates, and client-side data management.

The game is inspired by the match-3 puzzle genre and is developed independently for educational and portfolio purposes.

## Features

- **Match-3 Mechanics:** Match three or more adjacent candies horizontally or vertically.
- **Special Candies:** Generate special candies through specific matching combinations.
- **Level Progression:** Complete multiple levels with varying objectives.
- **Scoring System:** Earn points through successful matches.
- **Move Management:** Complete objectives within the available moves.
- **Sound Controls:** Enable or disable game audio.
- **Board Shuffle:** Rearrange the board when no valid moves are available.
- **Local Data Persistence:** Store selected game progress and scores using browser Local Storage.
- **Responsive Interface:** Support different screen sizes and devices.

## Getting Started

### Prerequisites
- A modern web browser.
- Visual Studio Code (recommended for development).

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/codebyselina/candy-crush.git
   ```

2. Navigate to the project directory.
3. Open the folder in Visual Studio Code.
4. Run `index.html` using Live Server or open it directly in a browser.
